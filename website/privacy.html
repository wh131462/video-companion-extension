隐私政策

最后更新日期：2025年1月14日

核心承诺

本扩展不收集、存储或传输任何用户个人数据。

概述

Video Companion（以下简称"本扩展"）是一款用于增强网页视频播放体验的浏览器扩展。我们非常重视用户隐私，本隐私政策旨在说明本扩展如何处理用户数据。

1. 数据收集

我们不收集的数据

  • 个人身份信息（姓名、邮箱、电话等）
  • 浏览历史记录
  • 搜索查询
  • 密码或登录凭证
  • 支付信息
  • 位置数据
  • IP 地址
  • 设备标识符

本地存储的数据

本扩展仅在用户本地浏览器中存储以下设置偏好：

数据类型 用途 存储位置
默认播放速度 记住用户偏好的播放速度 本地 Chrome Storage
面板显示设置 记住控制面板显示偏好 本地 Chrome Storage
自动隐藏延迟 自定义面板自动隐藏时间 本地 Chrome Storage

这些数据完全存储在用户本地设备上，不会上传到任何服务器，不会与任何第三方共享，用户可随时通过卸载扩展来删除。

2. 权限使用说明

本扩展请求以下浏览器权限，仅用于实现核心功能：

主机权限 (<all_urls>)

用于检测并增强任意网页中的 HTML5 视频元素。视频可能出现在任何网站上，扩展需要能够识别并为这些视频添加控制功能。

activeTab 权限

在用户主动点击扩展图标或使用快捷键时，获取当前标签页的访问权限。仅在用户主动交互时激活。

scripting 权限

将内容脚本注入网页，以实现视频检测和控制面板功能。

storage 权限

在本地存储用户设置偏好。

contextMenus 权限

在用户右键点击视频时显示快捷菜单，提供画中画、截图等快捷操作。

3. 第三方服务

本扩展：

  • ✕ 不使用任何第三方分析服务
  • ✕ 不使用任何广告服务
  • ✕ 不使用任何用户追踪服务
  • ✕ 不连接任何外部服务器
  • ✕ 不加载任何远程代码

所有功能代码均在本地打包，完全离线运行。

4. 数据安全

  • 本扩展不传输任何数据，因此不存在数据泄露风险
  • 所有本地存储的设置使用 Chrome 官方提供的 Storage API，受浏览器安全机制保护
  • 源代码开源，接受公众审查

5. 用户权利

用户有权：

  • 访问：查看本扩展存储的所有本地数据（通过 Chrome 开发者工具）
  • 删除：通过卸载扩展删除所有本地数据
  • 控制：随时禁用或启用扩展

6. 合规声明

本扩展遵守：

  • Chrome Web Store 开发者计划政策
  • 通用数据保护条例 (GDPR) 的相关要求
  • 加州消费者隐私法案 (CCPA) 的相关要求

Core Commitment

This Extension does not collect, store, or transmit any personal user data.

Overview

Video Companion is a browser extension designed to enhance the web video playback experience. We take user privacy seriously. This privacy policy explains how this Extension handles user data.

1. Data Collection

Data We Do Not Collect

  • Personal identification information (name, email, phone, etc.)
  • Browsing history
  • Search queries
  • Passwords or login credentials
  • Payment information
  • Location data
  • IP addresses
  • Device identifiers

Locally Stored Data

This Extension only stores the following preferences locally in the user's browser:

Data Type Purpose Storage Location
Default playback speed Remember user's preferred playback speed Local Chrome Storage
Panel display settings Remember control panel display preferences Local Chrome Storage
Auto-hide delay Customize panel auto-hide timing Local Chrome Storage

This data is stored entirely on the user's local device, is never uploaded to any server, is never shared with any third party, and can be deleted at any time by uninstalling the Extension.

2. Permission Usage

This Extension requests the following browser permissions, used solely for core functionality:

Host Permissions (<all_urls>)

Used to detect and enhance HTML5 video elements on any webpage. Videos can appear on any website, and the Extension needs to identify and add control features to them.

activeTab Permission

Gains access to the current tab when the user actively clicks the Extension icon or uses a keyboard shortcut. Only activated on user interaction.

scripting Permission

Injects content scripts into webpages to enable video detection and control panel functionality.

storage Permission

Stores user preferences locally.

contextMenus Permission

Displays a quick-access menu when the user right-clicks a video, providing shortcuts for picture-in-picture, screenshot, and other actions.

3. Third-Party Services

This Extension:

  • ✕ Does not use any third-party analytics services
  • ✕ Does not use any advertising services
  • ✕ Does not use any user tracking services
  • ✕ Does not connect to any external servers
  • ✕ Does not load any remote code

All functionality is bundled locally and runs completely offline.

4. Data Security

  • This Extension does not transmit any data, so there is no risk of data leakage
  • All locally stored settings use Chrome's official Storage API, protected by browser security mechanisms
  • Source code is open source and open to public scrutiny

5. User Rights

Users have the right to:

  • Access: View all local data stored by this Extension (via Chrome Developer Tools)
  • Delete: Remove all local data by uninstalling the Extension
  • Control: Disable or enable the Extension at any time

6. Compliance

This Extension complies with:

  • Chrome Web Store Developer Program Policies
  • General Data Protection Regulation (GDPR) requirements
  • California Consumer Privacy Act (CCPA) requirements
