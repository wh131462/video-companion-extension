源码安装步骤

# 1. 克隆仓库 git clone https://github.com/wh131462/video-companion-extension.git cd video-companion-extension # 2. 安装依赖并构建 npm install npm run build
  1. 打开 Chrome 浏览器，访问 chrome://extensions/
  2. 开启右上角「开发者模式」
  3. 点击「加载已解压的扩展程序」
  4. 选择项目的 dist 目录
